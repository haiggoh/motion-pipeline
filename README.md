# motion-pipeline (DRAFT — Task 12 finalises per the approved README direction)

A reusable, publishable kinetic-typography render pipeline with a no-code project menu.
Feed in CI colours + a font + a transcript (+ optional voiceover) → get back a finished
10-bit text-animation video timed to the voiceover. No AI inside the pipeline; an AI
session can add creative graphics on the generated project folder afterwards
(recommended: [free-agents](https://github.com/haiggoh/free-agents)).

Status: scaffold only (Task 1). See `~/.claude/plans/2026-11-08-motion-pipeline-implementation-plan.md`.
